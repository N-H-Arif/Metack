## When to use
Use this skill for standard career tasks where the agent performs the role of **interview**.

## Discovery guidance
This skill provides broad career support and is suitable for routine requests.
It is not specialized for any single constraint pattern.

## Workflow
1. Read the task and identify the requested output.
2. Extract general constraints and key entities.
3. Produce a simple recommendation for the interview subtask.
4. Return a concise handoff-friendly summary.

## Good patterns
- routine subtasks
- simple filtering support
- handoff-friendly summaries

## Examples
- A standard career request involving interview
- A routine task with a few simple constraints
- A request needing a short structured response
